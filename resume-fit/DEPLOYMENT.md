# Render Free demo

Use Blueprint path `resume-fit/render.yaml` on the `main` branch. The service uses the **Free** compute plan and no persistent disk.

- React, the Node backend and Python PDF processing run in the same Docker service.
- Saved drafts, test purchases and the daily AI counter are temporary and can disappear on sleep, restart or redeploy.
- `FREE_HOSTING_DEMO=true` blocks creating real Razorpay payments, even if live keys are accidentally supplied. Downloads retain the payment gate. Optional simulated checkout requires Razorpay Test Mode credentials; this demo does not collect real money.
- `MAX_AI_REQUESTS_PER_DAY=0` disables AI requests by default. OpenAI API usage is separate from free hosting. Enabling AI requires valid API billing/credits and a positive cap; the request count cap resets when ephemeral storage is lost.
- `SESSION_SECRET` is generated by the Blueprint. Keep it stable; saved history is isolated by signed browser cookies, not user accounts.
- `APP_ORIGIN` uses Render's `RENDER_EXTERNAL_URL` automatically unless you set a custom origin.
- Render Free services sleep after 15 idle minutes and can take about a minute to wake up. Monthly limits apply.

Never put `.env` or secret API keys in GitHub. Set optional keys only in Render's server environment settings. No paid compute or disk is included in this Blueprint. Review Render billing/spending limits if your workspace has a payment method.

A reliable production payment service needs durable database/file storage before real checkout is enabled. Do not set `FREE_HOSTING_DEMO=false` on ephemeral storage to collect real payments.

Official limits: https://render.com/docs/free
